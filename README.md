# WedConnect

WedConnect bringt Hochzeitspaare und Hochzeitsfotografen zusammen, wenn Hochzeit, Ort, Bildsprache und Erwartungen zueinander passen.

## Aktueller Arbeitsstand

Die aktuelle Demo steht in `index.html` und `prototype/index.html` im Hauptzweig. Der visuell freigegebene Ausgangsstand bleibt unverändert im Branch [baseline/2026-10-10-pairing-demo](https://github.com/Supersheriff1/WedConnect/tree/baseline/2026-10-10-pairing-demo).

## Lokal ansehen

Die Datei `index.html` oder `prototype/index.html` herunterladen und im Browser öffnen. Sie benötigt keinen Build-Schritt und kein Backend. Google Fonts werden bei verfügbarer Internetverbindung geladen; andernfalls greifen die Fallback-Schriften.

## Status

Die Demo ist ein interaktiver UI-Prototyp. Anmeldung, Profile, Matching, Nachrichten und Speicherung sind noch nicht an ein Backend angeschlossen.
